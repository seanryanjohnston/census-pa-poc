# Archived precinct route

This directory is frozen `POC030` evidence. It contains the abandoned
fixed/actual-precinct code path, planning mappings, documentation, tests,
accepted proof artifacts, and ignored generated data.

Do not import modules or select products from this tree in the active direct
legislative pipeline. The inventory and disposition reasons are recorded in
`mappings/poc030_archive_manifest_v1.csv` at the repository root.

The archive is recoverable and was created by moves rather than deletion.
Pre-`POC030` canonical snapshots are under `docs/` in this directory.
